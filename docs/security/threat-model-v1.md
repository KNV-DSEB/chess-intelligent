# Academy and deployment threat model V1

Task 013 distinguishes automated implementation evidence from deployed evidence. `PASS (automated)` below means the control was exercised through Fastify/PGlite integration tests; it is not a claim about a real HTTPS browser or real PostgreSQL deployment. `NOT_RUN` items are production-gate blockers where specified.

| Asset / threat                         | Mitigation                                                                                       | Test performed                                           | Result                                                       | Remaining risk                                                              |
| -------------------------------------- | ------------------------------------------------------------------------------------------------ | -------------------------------------------------------- | ------------------------------------------------------------ | --------------------------------------------------------------------------- |
| User credential theft                  | Argon2id; credential table separation; password fields redacted                                  | Hash/login/change/reset regression                       | PASS (automated)                                             | No MFA, breached-password screening, or formal penetration test             |
| Session token theft/replay             | 256-bit token; SHA-256 at rest; revoke/expiry; production `__Host-` cookie                       | Cookie header injection and session lifecycle regression | PASS (automated); real HTTPS `NOT_RUN`                       | Compromised browser can use a live session; no device inventory             |
| Cross-tenant IDOR                      | Session-derived active membership plus Academy predicates/FKs                                    | Two-Academy and direct-ID regression                     | PASS (automated); browser matrix `NOT_RUN`                   | New routes can drift without catalog/review                                 |
| Last Owner removal / escalation        | Canonical RBAC and transaction-locked last-Owner check                                           | Task 012 role/concurrency regression                     | PASS (PGlite); real PostgreSQL concurrency `NOT_RUN`         | No multi-party approval for Owner actions                                   |
| Coach creates Student evidence         | Student path derives User → Student membership → Profile → Player → assignment                   | Coach impersonation regression                           | PASS (automated); deployed browser/API `NOT_RUN`             | Stolen Student session/shared device                                        |
| Invitation link theft/replay           | High-entropy single-use token; digest only; email-bound claim; expiry                            | Persistence, response, reuse, redaction regression       | PASS (automated); SMTP/browser `NOT_RUN`                     | Possession of delivered email link is not independently verified identity   |
| Password-reset theft/replay            | One-hour policy; digest only; single-use atomic consume; prior token/session revocation          | Concurrent reuse, old-session, old/new login regression  | PASS (PGlite); real PostgreSQL/SMTP/browser `NOT_RUN`        | Mailbox or SMTP compromise can expose a live link                           |
| Account enumeration / reset flooding   | Generic public response, dummy/provider-equivalent path, three requests/hour identifier throttle | Known/unknown and throttle regression                    | PASS (automated)                                             | Identifier-only throttle can be distributed or abused for temporary denial  |
| SMTP failure or compromise             | Provider-neutral boundary; controlled delivery state/audit; no provider error to client          | Recording/failing adapter regression                     | PASS (automated); Mailpit/real SMTP `NOT_RUN`                | V1 has no durable asynchronous retry queue; SMTP operator controls delivery |
| CSRF / CORS bypass                     | SameSite=Lax; exact Origin on cookie mutations; explicit credentialed origins                    | Allowed/foreign Origin and CORS injection                | PASS (automated); real HTTPS/browser `NOT_RUN`               | Same-origin XSS bypasses Origin defense                                     |
| Reverse-proxy misconfiguration         | API not publicly published in Compose; explicit `TRUST_PROXY`; Caddy TLS boundary                | Compose config parsed                                    | PASS (static); live proxy `NOT_RUN`                          | Wrong host/TLS/forwarded-header policy in operator environment              |
| Secure-cookie downgrade                | Production config refuses insecure cookie or internal routes                                     | Config regression                                        | PASS (automated); actual `Set-Cookie` `NOT_RUN`              | Deployment environment remains unproved                                     |
| Database exposure / dependency failure | Internal Compose network; bounded pool/timeouts; readiness checks DB/schema; failures deny       | Compose static check and failing DB double               | PASS (automated/static); outage on real deployment `NOT_RUN` | Runtime DB role owns schema in V1; no network/firewall proof                |
| Secret leakage in logs                 | Pino redaction; token URL sanitizer; sanitized 500; metadata validation                          | URL/error/audit regression and repository secret scan    | PASS (automated/static)                                      | Third-party infrastructure logs need operator review                        |
| Backup leakage / unusable backup       | Git ignores dumps/manifests; explicit target; custom dump; separate restore/hash comparison      | Tooling/static review only                               | `NOT_RUN`                                                    | Backup encryption/access controls are infrastructure responsibilities       |
| Migration partial apply                | Transactional runner; explicit one-shot migration; failed-migration rehearsal command            | PGlite migration; real rehearsal unavailable             | PASS (PGlite); real PostgreSQL `NOT_RUN`                     | PostgreSQL-specific constraint/query behavior remains unproved              |
| Audit tampering/amplification          | Append-only trigger; bounded listing; denial metadata is secret-checked                          | Regression and benchmark harness review                  | PASS (automated/static); benchmark/denial load `NOT_RUN`     | DB superuser can alter infrastructure; load behavior unmeasured             |
| Minor access / consent bypass          | Explicit Academy attestation gates future scored attempts; history retained                      | Pending/grant/revoke regression                          | PASS (automated); browser `NOT_RUN`                          | Attestation is not guardian identity or legal-compliance proof              |

Backup dumps and restore manifests contain sensitive application data. They must not be committed and must be protected by operator storage controls. The repository makes no unsupported encryption-at-rest, RPO, or RTO claim.
