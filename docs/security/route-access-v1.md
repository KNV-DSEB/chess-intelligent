# API route access catalog V1

The production default has `INTERNAL_DEV_ROUTES=false`. Internal routes respond as unavailable when that flag is off; production configuration rejects enabling it.

| Route family                                                                                                       | Classification                   | Capability / scope                                                                        | Self-only         |
| ------------------------------------------------------------------------------------------------------------------ | -------------------------------- | ----------------------------------------------------------------------------------------- | ----------------- |
| `GET /health`, `GET /livez`                                                                                        | PUBLIC                           | process liveness only                                                                     | no                |
| `GET /readyz`                                                                                                      | PUBLIC                           | PostgreSQL connectivity and current schema; SMTP configuration is reported                | no                |
| `POST /auth/login`                                                                                                 | PUBLIC                           | rate limited                                                                              | no                |
| `POST /auth/password-reset/request`, `POST /auth/password-reset/complete`                                          | PUBLIC                           | generic request response; exact single-use reset bearer for completion                    | reset bearer      |
| `POST /auth/logout`, `GET /auth/me`, `POST /auth/password`, `POST /auth/sessions/revoke-all`, `POST /auth/disable` | AUTHENTICATED                    | current User/session; disable requires current password                                   | yes               |
| `GET/POST /auth/invitations/:token[/accept]`                                                                       | PUBLIC or optional authenticated | exact raw token; acceptance email must match                                              | invitation bearer |
| `GET /ontology/**`                                                                                                 | PUBLIC RESEARCH READ             | immutable published ontology                                                              | no                |
| `GET /intelligence/concept-coverage`                                                                               | PUBLIC RESEARCH READ             | explicit ontology version; system support only                                            | no                |
| `GET /analysis/**`, `GET /classification/**`, `GET /games/:id/**`                                                  | PUBLIC RESEARCH READ             | canonical historical/engine evidence                                                      | no                |
| `POST /analysis/jobs`, `POST /classification/games/:id`                                                            | INTERNAL_DEV_ONLY                | explicit production gate                                                                  | no                |
| `POST /games/import-*`, `/games/reconcile-pgn`, `/games/:id/attach-pgn`                                            | INTERNAL_DEV_ONLY                | explicit production gate                                                                  | no                |
| `GET /players/**`, `POST /positions/explore`, `POST /preparation/**`, `POST /intelligence/player-dossier`          | PUBLIC RESEARCH                  | corpus/engine evidence; no Academy actor semantics                                        | no                |
| `POST /intelligence/player-skill-graph`, `GET /skill-graph/**`, `GET /players/:id/skill-graph-runs`                | INTERNAL_DEV_ONLY                | arbitrary Player artifact access disabled in production                                   | no                |
| `POST/GET /training/plans/**`                                                                                      | INTERNAL_DEV_ONLY                | arbitrary Player/plan access disabled in production                                       | no                |
| `GET /training/items/:id`                                                                                          | AUTHENTICATED STUDENT            | exact active Academy assignment                                                           | yes               |
| `POST /training/items/:id/attempts`                                                                                | AUTHENTICATED STUDENT            | exact assignment + consent + derived Player                                               | yes               |
| `GET /training/attempts/:id`                                                                                       | AUTHENTICATED STUDENT            | attempt Player and assigned item must match                                               | yes               |
| `POST /academies`                                                                                                  | INTERNAL_DEV_ONLY                | first Academy uses CLI bootstrap                                                          | no                |
| `GET/POST/PATCH /academies/:id/memberships`, invitations, consent, audit                                           | ACADEMY_PROTECTED                | `MEMBERSHIP_MANAGE`, `INVITATION_MANAGE`, `CONSENT_MANAGE`, or `AUDIT_READ`; same Academy | no                |
| `POST /academies/:id/memberships`, `POST /academies/:id/students`                                                  | ACADEMY_PROTECTED                | `MEMBERSHIP_MANAGE`; same Academy                                                         | no                |
| `GET /academies/:id/roster`                                                                                        | ACADEMY_PROTECTED                | `ROSTER_READ`; same Academy                                                               | no                |
| `GET /academies/:id/students/:studentId/intelligence`                                                              | ACADEMY_PROTECTED                | `STUDENT_INTELLIGENCE_READ`; StudentProfile constrained to Academy                        | no                |
| `POST /academies/:id/students/:studentId/skill-graph`                                                              | ACADEMY_PROTECTED                | `STUDENT_INTELLIGENCE_READ`; Player derived from StudentProfile                           | no                |
| `GET /academies/:id/students/:studentId/skill-graph/:runId[/concepts/:stableId]`                                   | ACADEMY_PROTECTED                | `STUDENT_INTELLIGENCE_READ`; run Player constrained to StudentProfile                     | no                |
| `POST/GET /academies/:id/students/:studentId/ai-briefs/**`                                                         | ACADEMY_PROTECTED                | `STUDENT_INTELLIGENCE_READ`; exact graph/plan/evidence snapshot                           | no                |
| `GET/POST /academies/:id/**/assignments[/cancel]`                                                                  | ACADEMY_PROTECTED                | `ASSIGNMENT_READ` / `ASSIGNMENT_WRITE`; same Academy                                      | no                |
| `POST /intelligence/student-progress`                                                                              | ACADEMY_PROTECTED                | Academy ID plus `STUDENT_INTELLIGENCE_READ`; both runs must match Student Player          | no                |
| `GET /academies/:id/me/intelligence`, `GET /academies/:id/me/assignments`                                          | AUTHENTICATED STUDENT            | own membership/Profile and consent                                                        | yes               |
| `GET /academies/:id/me/skill-graph/:runId[/concepts/:stableId]`, `POST/GET /academies/:id/me/ai-briefs/**`         | AUTHENTICATED STUDENT            | own Player/run plus consent; Student brief audience only                                  | yes               |

Authentication failure is 401. Authenticated denial is 403. Tenant denial does not return target Student/resource metadata and is audited. Validation remains 400; absent in-scope resources are 404; immutable/lifecycle conflicts are 409; expired invitations are 410. Production invitation creation delivers through the configured email provider and never returns the raw token. Development-only raw-token response behavior exists only while `INTERNAL_DEV_ROUTES=true`, which production configuration rejects.
