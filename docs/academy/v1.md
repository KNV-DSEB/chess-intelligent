# Academy workflow policies V1

Canonical constants and pure functions live in `packages/domain/src/coach-student-intelligence.ts`.

## STUDENT_PROGRESS_COMPARISON_V1

Two SkillGraphRuns are comparable only when all are equal:

```text
playerId
ontologyVersion
skillGraphPolicyVersion
policyConfigSha256
evidenceScopeSha256
classifierBundleVersion
classifierConfigSha256
classificationSelectionPolicyVersion
```

`to.asOfDate` must be greater than or equal to `from.asOfDate`. `evidenceSnapshotSha256` is deliberately excluded: different selected evidence is the expected reason to compare longitudinal runs.

Failure returns `NOT_COMPARABLE` with one or more of:

```text
DIFFERENT_PLAYER
DIFFERENT_ONTOLOGY
DIFFERENT_SKILL_GRAPH_POLICY
DIFFERENT_POLICY_CONFIG
DIFFERENT_EVIDENCE_SCOPE
INCOMPATIBLE_CLASSIFIER_SEMANTICS
REVERSED_AS_OF_DATE
```

No posterior, evidence-mass, confidence, band, unit, or coverage delta is returned when not comparable. Comparable deltas are factual measurement changes; no automatic improved/regressed interpretation exists.

## TRAINING_ASSIGNMENT_POLICY_V1

At assignment creation:

```text
no prior scored attempt       → MEASUREMENT_ELIGIBLE
prior remediation attempt     → PRACTICE_ONLY_ALREADY_MEASURED
prior diagnostic attempt      → reject DIAGNOSTIC_ITEM_ALREADY_MEASURED
```

Every selected item must belong to the exact TrainingPlan and Player. The baseline must equal `TrainingPlanRun.skillGraphRunId`.

One item is complete when its first scored Task 010 attempt for the same Player and TrainingItem has `submittedAt >= assignment.assignedAt`. Attempts before assignment are ignored. `CORRECT` and `INCORRECT` both complete workflow. Retries remain visible without another completion or measurement-status change.

An assignment is `CANCELLED` when `cancelledAt` exists, otherwise `COMPLETED` when every item is complete, otherwise `ACTIVE`. `OVERDUE` is derived only for an active assignment whose due date is before the explicit current date.

Assignment and note persistence creates zero mastery/concept/training evidence. Only the existing Task 010 attempt transaction creates `training.attempt` evidence.

## COACH_ATTENTION_SIGNAL_V1

Signals are evaluated in this stable order:

1. `NO_COMPATIBLE_SKILL_GRAPH` when no exact-profile graph exists.
2. `SKILL_GRAPH_REFRESH_AVAILABLE` when exact first-scored training evidence is not selected by the compatible graph.
3. `ACTIVE_ASSIGNMENT_OVERDUE` when any active assignment is past due.
4. `ACTIVE_ASSIGNMENT_NO_RECENT_ACTIVITY` when an active assignment exists and neither assignment creation nor later training activity occurred within seven calendar days.
5. `ASSIGNMENT_COMPLETED_REVIEW_AVAILABLE` when a completed assignment has first-scored evidence outside the current compatible graph.

These signals describe workflow state. They never describe Student quality and are never used to rank Students.
