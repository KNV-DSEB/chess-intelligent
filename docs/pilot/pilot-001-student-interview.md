1. Could you find the next assigned item without help?
2. Did Practice versus Assessment make sense?
3. Before submitting, was it clear that the answer was hidden and the first attempt mattered?
4. After submitting, did the result and evidence explanation feel understandable?

6. If an AI brief appeared, was it useful, too vague, incorrect, already known, or not actionable?
7. Did any error prevent training? What did you try next?
8. What single change would make the next session easier?
