# Pilot 001 Coach guide

1. Open a Student from the Academy roster. Confirm the readiness label before interpreting the
   learning surface.
2. Read coverage denominators first. No evidence, insufficient evidence, and unsupported concepts
   are different states and none is a weakness label.
3. Inspect exact concept evidence before agreeing with a displayed priority. Record Agree, Unsure,
   or Disagree; feedback is operational and never changes mastery.
4. Optionally generate a grounded brief. Open its citations and rate claims. AI explains the pinned
   snapshot; it does not create chess truth or recommendations.
5. Create a TrainingPlan explicitly from the current immutable Skill Graph. Select eligible items
   and create the assignment. Assignment creation creates no evidence.
6. After the Student completes work, explicitly refresh the Skill Graph and compare only compatible
   runs. Counts and transitions are evidence observations, not a claim of learning effectiveness.

If AI is unavailable, continue with the structured Skill Graph, evidence trail, plan, assignment, and
progress workflow. Report blocking or misleading behavior through the support protocol.
