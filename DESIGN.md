# Chess Intelligent design system

## Product character

Calm academy authority, evidence before opinion, and serious chess without database-software
clutter. The interface should feel trustworthy to a coach and approachable to a student.

## Visual world

The Pilot uses a master-game folio: warm paper, deep-forest authority surfaces, amber pencil
annotations, score-sheet rows, and chess positions as the primary evidence surface. It refuses the
generic equal-weight analytics card grid.

## Tokens

- Canvas #f2eee3, paper #fffdf6, ink #17231c, soft ink #4d5d52.
- Forest #1d5a42 for primary action; deep forest #102d22 for authority surfaces.
- Amber #a76522 and amber wash #f5e6ca for annotation and review attention.
- 4/8px spacing rhythm; radii 10–16px; shadows only for hierarchy.
- Editorial serif headings and quiet sans body; no runtime font request.

## Components

- Focus ledgers carry operational signals and never rank students by mastery.
- Priority rows carry concept, evidence state, explanation, and one quiet evidence action.
- Skill domains group the whole ontology and distinguish system capability from Student evidence.
- Evidence folios show the exact board, nearby moves, classification meaning, compatible engine
  provenance, and advanced lineage IDs.
- Grounded AI is an optional collapsed explanation surface, absent from primary navigation.
- Training positions lead with the board and keep reference moves private before submission.

## Interaction and accessibility

Primary controls are at least 44px high, keyboard focus is visible, a skip link reaches main
content, controls have text labels, headings are sequential, status/error updates use semantic
roles, and reduced motion disables nonessential transitions. Color never carries state alone. No
autoplay or gesture-only behavior.

## Content rules

Say “not yet supported,” “no evidence yet,” “early signal,” or “evidence estimate.” Use “learning
picture” in primary UI and move run IDs, hashes, policy configuration, and evidence roles into
advanced provenance. Never use weakness, psychology, guaranteed improvement, or effectiveness
language where only activity/measurement exists.
